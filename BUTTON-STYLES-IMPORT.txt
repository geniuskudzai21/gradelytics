1. FONTS (required — buttons use Space Grotesk heading font)
------------------------------------------------------------------------
Add to your HTML <head> (before your stylesheet):

  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Space+Grotesk:wght@500;600;700&display=swap" rel="stylesheet">

  --font-heading: 'Space Grotesk', sans-serif;
  --font-body:    'Inter', sans-serif;

------------------------------------------------------------------------
2. DESIGN TOKENS (CSS variables — define on :root)
------------------------------------------------------------------------
:root {
  colors us the 1s already in the styles.css

  /* Spacing (8px scale) */
  --sp-2:  8px;
  --sp-3: 12px;
  --sp-4: 16px;
  --sp-5: 20px;

  /* Radius */
  --radius-sm:   6px;
  --radius-md:   8px;
  --radius-lg:   12px;

  /* Shadows */
  --shadow-sm:     0 1px 3px rgba(var(--color-ink-rgb), 0.10), 0 1px 2px rgba(var(--color-ink-rgb), 0.06);
  --shadow-blue:   0 4px 14px -2px rgba(var(--color-primary-rgb), 0.30);
  --shadow-blue-lg:0 8px 24px -4px rgba(var(--color-primary-rgb), 0.35);

  /* Transitions */
  --ease-out:      cubic-bezier(0.16, 1, 0.3, 1);
  --duration-fast: 150ms;
  --duration-base: 200ms;
  --duration-slow: 300ms;
}

IMPORTANT NOTES
  * The .btn-primary glossy look comes from the stacked background
    gradient + blue glow shadow + inset top highlight. All three layers
    are required — drop any one and it looks flat.
  * Font is the biggest factor: buttons render in 'Space Grotesk' 600.
    If you skip the Google Fonts link, everything shifts to sans-serif.
  * There are TWO variants of .btn in this project:
      - App/dashboard (style.css): font-heading, 10px/20px padding,
        14px text, gap 8px.
      - Landing page (landing.css): same font, different paddings,
        plus the ::after sheen on .btn-primary.
      - Admin panel (admin.css): compact, 13px Inter, 9px/14px padding,
        flat (no gradient). Copy the variant that matches your page.
  * Admin panel uses flat buttons (no gradient/glow):
      .btn { display:inline-flex; align-items:center; justify-content:center;
             gap:var(--sp-2); padding:9px 14px;
             font:600 13px/1 var(--font-body);
             border-radius:var(--radius-md); border:1px solid transparent;
             cursor:pointer; transition:background var(--duration-fast),
             border-color var(--duration-fast), color var(--duration-fast); }
      .btn-outline { background:var(--surface-alt); color:var(--text-light); border-color:var(--border); }
      .btn-outline:hover { border-color:var(--primary); color:var(--ink); }
      .btn-primary { background:var(--primary); color:#fff; }
      .btn-primary:hover { background:var(--primary-hover); }
      .btn-danger { background:var(--danger); color:#fff; }
      .btn-danger:hover { filter:brightness(0.92); }
      .btn-sm { padding:7px 11px; font-size:12px; }
      .btn-block { width:100%; }
